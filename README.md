# Старт-Агент

**Академия Финтеха 2026 · трек «Финтех без границ»**

Мобильный кликабельный веб-прототип AI-навигатора банка для предпринимателей 17–25 лет. Агент-маскот Буст помогает пройти путь от проверки идеи до первого платежа, предлагая банковские инструменты тогда, когда они действительно нужны.

## Сценарий пользователя

Пользователь описывает идею → Буст анализирует её → показывает факты и гипотезы → предлагает провести пять интервью → помогает собрать короткий пилот → показывает переход к бизнесу и демонстрационному расчётному счёту. Чат отвечает на вопросы о следующем шаге, господдержке, РКО и эквайринге ВТБ. Действия в чате требуют кнопки «Подтвердить».

## Экраны

| Адрес | Экран |
| --- | --- |
| `/` | Промо: идея, инструменты, начало без счёта |
| `/onboarding` | Описание идеи и анализ Буста |
| `/hypotheses` | Карта фактов и гипотез |
| `/agent` | Главная с агентом, статистикой и курсами |
| `/mission` | Задачи, раскрывающиеся курсы, счётчик интервью |
| `/pilot` | Предложение 4-недельного практикума |
| `/growth` | Диалог о переходе от пилота к бизнесу |
| `/account` | Демонстрационный счёт и прогноз |

Центральная молния открывает чат с Бустом поверх текущего экрана. Нижняя навигация связывает основные экраны. После открытия демонстрационного счёта «Главная» ведёт на `/account`.

## Стек

React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui; TanStack Start / Router, Vite, Lucide React. Маскот — собственный SVG. Интерфейс на русском, телефонная колонка 390px адаптируется к меньшим экранам.

## Локальный запуск

Понадобятся Node.js и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет сервер разработки. Проверка маршрутов: `npm test`.

## Ограничения прототипа

Бэкенда, регистрации и реальных банковских операций нет. Все суммы, выводы и ответы — моки. Данные хранятся в памяти текущего сеанса и сбрасываются при обновлении страницы. Голосовой ввод демонстрационный. Курсы открывают короткие материалы в чате; оформление счёта лишь меняет экран. Никакие заявки не отправляются, средства не переводятся.
